info Standalone Plot Instructions

Because this file will be executed directly from the printer, it contains an automated safety sequence:

Crucial: Auto Bed Leveling, Timelapse, Flow Calibration, and any other pre-print add-ons or calibrations MUST be toggled OFF when starting this print to prevent toolhead collisions.
  1. Transfer the downloaded .gcode file onto the printer's MicroSD card, make sure all calibrations/add-ons are unchecked, and start the job.
  2. Pause 1 (Safety Warning): The printer will immediately pause. Make sure your pen/attachment is REMOVED so it does not collide with the bed, then press Resume.
  3. Homing: The machine will safely home all axes and move the toolhead to the side.
  4. Pause 2 (Energized Setup): The printer will pause again with motors locked. Mount your paper and pen, set your contact height, and press Resume to plot!

Note: Long pauses after pressing Resume are completely normal while the firmware processes commands.
